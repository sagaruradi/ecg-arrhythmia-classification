# Viva Notes — ECG Arrhythmia Classification with a 1D-CNN

## A. 60-second project explanation

“My project demonstrates heartbeat-pattern classification from the MIT-BIH Arrhythmia Database. Each record contains ECG samples, header information, and expert annotations. I use WFDB to read one ECG channel and its beat locations. SciPy applies a bandpass filter, then I cut a fixed window around each supported annotated beat and normalize it. Whole recordings are assigned to separate training, validation, and test groups before windows are made, which prevents beats from the same record leaking between these groups. A small 1D convolutional neural network learns patterns from the training windows. I choose the checkpoint with the lowest validation loss and report accuracy, precision, recall, F1-score, and a confusion matrix on held-out recordings. Streamlit displays the signal, a saved-model prediction, and the actual generated results. This is an educational experiment, not a medical diagnostic system.”

## B. Problem statement

Long ECG recordings contain many beats. Reviewing every beat manually can be slow. This project demonstrates a basic method to group annotated heartbeats into a few known patterns using signal processing and a small neural network. It does not replace a cardiologist.

## C. Dataset

- **ECG:** Electrocardiogram; a recording of electrical activity measured from the heart over time.
- **MIT-BIH:** A public research database of annotated ECG recordings collected for arrhythmia research. This project reads the copy present in the workspace.
- **`.dat`:** Encoded signal samples.
- **`.hea`:** Header with sampling frequency, channel information, and signal metadata.
- **`.atr`:** Annotation stream containing expert beat locations and symbols.
- **Annotations:** Reference positions and beat symbols. The model learns labels derived from these symbols; they are not generated by the model.
- **Project groups:** N/L/R/e/j → Normal; A/a/J/S → Supraventricular ectopic; V/E → Ventricular ectopic; F → Fusion. Other symbols are unsupported for this four-class task and excluded.

## D. How the program works

1. **Signal loading:** `src/data_loader.py` checks for matching `.hea`, `.dat`, and `.atr` files and uses WFDB to read channel 0 and annotations.
2. **Filtering:** `src/preprocessing.py` uses a Butterworth bandpass between 0.5 Hz and at most 40 Hz to reduce slow baseline movement and high-frequency noise.
3. **Heartbeat segmentation:** For every annotated beat, the program takes a 0.6-second window: 0.2 seconds before and 0.4 seconds after the annotation sample. Segments that cross record boundaries are skipped.
4. **Label assignment:** The annotation symbol is mapped only when it is in the documented symbol table. Unknown symbols are counted and excluded, not guessed.
5. **CNN training:** Curated whole-record groups are assigned before windows are used. The CNN trains on training-record windows for five epochs using Adam and class-weighted cross-entropy. Validation loss selects the saved model.
6. **Prediction:** The saved model produces class scores. Softmax converts these to probabilities; the largest probability is the predicted class. The dashboard loads the checkpoint and does not retrain. If hosted without the local dataset, it can fetch the selected public record from PhysioNet.
7. **Evaluation:** Metrics are calculated on test records not used for training. Generated files and processed record counts are described in `README.md` and recorded in the dataset manifest.

## E. CNN concepts in simple terms

- **Convolution:** A small learned filter slides over the ECG samples and responds to local shapes, such as a sharp rise or a wider waveform.
- **ReLU:** Keeps positive activations and changes negative activations to zero, allowing the network to learn non-linear patterns.
- **Max pooling:** Keeps a strong local response while reducing the sequence length, making later computation smaller.
- **Global average pooling:** Averages each learned feature map over time to summarize whether that pattern appeared in the heartbeat.
- **Output layer:** Produces one score per class. During prediction, softmax turns scores into probabilities that sum to one.
- **1D-CNN:** Convolution moves along one dimension—time—because an ECG segment is a sequence.

## F. Likely viva questions and answers

1. **Why did you choose this project?**  
   It combines signal processing and machine learning on a real, annotated time-series dataset and has a clear end-to-end workflow.

2. **Why use MIT-BIH?**  
   It is a well-known research dataset with ECG signals and expert beat annotations, so the labels have a documented source.

3. **What is an ECG signal?**  
   It is a time-series measurement of the heart’s electrical activity.

4. **What is arrhythmia?**  
   It is an abnormality in the rhythm or timing of heartbeats. This project groups selected annotated beat patterns and does not diagnose all arrhythmias.

5. **Why use a CNN?**  
   Convolutional filters can learn local waveform shapes directly from the heartbeat samples.

6. **What is a 1D-CNN?**  
   It is a convolutional neural network whose filters slide along one axis, here the time axis of the ECG.

7. **Why is filtering necessary?**  
   ECG signals can contain slow baseline drift and high-frequency noise that obscure waveform patterns.

8. **What is heartbeat segmentation?**  
   Cutting a fixed-length window around an annotated heartbeat location.

9. **What are annotations?**  
   Expert-provided beat positions and symbols stored in the `.atr` file; they provide reference labels for this experiment.

10. **What is training versus testing?**  
    Training updates model weights. Testing measures performance on records withheld from those updates.

11. **Why split by record?**  
    A random beat-level split could place similar beats from one recording in both training and testing, making performance look overly optimistic.

12. **What is overfitting?**  
    It occurs when a model learns the training examples too specifically and performs worse on unseen data.

13. **What is class imbalance?**  
    Some heartbeat categories occur much more often than others. This project uses class-weighted loss, but a small dataset can still limit minority-class results.

14. **What is a confusion matrix?**  
    A table of actual versus predicted classes that shows which classes the model confuses.

15. **What are precision and recall?**  
    Precision asks how many predictions for a class were correct. Recall asks how many actual examples of that class were found.

16. **What is F1-score?**  
    A combined score that balances precision and recall.

17. **What are the limitations?**  
    There are few selected records, class counts may be uneven, and results are not clinically validated. Only selected annotation groups are modeled.

18. **What does “real-time” mean here?**  
    The title refers to the intended application area. This implementation classifies recorded, pre-segmented ECG beats; it does not demonstrate continuous live monitoring.

19. **How would you improve the project?**  
    Use more data, a defined patient-independent benchmark, robust per-class analysis, and a properly engineered live acquisition pipeline, followed by expert review and validation.

20. **Does it diagnose atrial fibrillation?**  
    No. It classifies a small set of beat annotation groups and is not a diagnostic system.

21. **Why use softmax?**  
    It converts the output scores into class probabilities for a simple confidence display.

22. **Why use a validation set?**  
    It helps choose the checkpoint without using test recordings to guide training.

23. **What does the `.hea` file do?**  
    It describes the recording, including its sampling frequency and signal channels.

24. **Why normalize each heartbeat?**  
    It standardizes its scale and offset so the model can focus more on waveform shape.

## G. Honest limitations

The current run used records 100, 106, 114, 200, 213, and 233 for training; 201 and 205 for validation; and 208 and 209 for testing. It processed 15,105 training beats, 4,618 validation beats, and 5,955 test beats. Test accuracy was 0.8821 and weighted F1 was 0.8381, but Supraventricular ectopic recall was 0.00 and Fusion recall was 0.21. So the overall accuracy does not mean the model recognizes every group well.

The initial version classifies recorded ECG segments around existing MIT-BIH annotations. It is not clinically validated, does not independently locate beats in arbitrary continuous signals, and is not necessarily a live wearable-device system. State both the good overall score and the weak minority-class results during the viva; do not describe the model as ready for diagnosis.
